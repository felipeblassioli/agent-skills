# Changelog

All notable changes to `gcp-log-investigation` should be recorded here.

The format is intentionally simple and release-oriented. Each released version
should link to its companion verification evidence in `VERIFICATION.md`.

## 0.1.0 - 2026-03-08

Initial release of the pack.

### Added

- portable `log-reader` subagent for GCP application log investigations
- `lite` and `strict` profiles
- strict project rule for production-safe summarization and redaction
- usage and production-safety guides
- committed verification and diagnosis notes from a redacted validation example
- roadmap and release policy documents for future pack evolution

### Validation

See `VERIFICATION.md` for:

- structural verification
- dry-run install verification
- redacted query validation against `SERVICE_NAME`
- follow-up diagnosis and recommended improvements
