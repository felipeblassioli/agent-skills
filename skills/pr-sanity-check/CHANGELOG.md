# Changelog

## 0.1.0 — October 2026

Initial version.

- Starts from the PR but reasons about the problem and the present production
  system; explicitly not another code review.
- Bounded discovery: direct references first, expand only when an adjacent item
  could change the goal, implementation, release ordering or risk.
- Three separate judgments plus an optional relation map, in a ~250–400 word briefing.
- Outcome test over error test: paired numerators/denominators, before/after cohorts.
