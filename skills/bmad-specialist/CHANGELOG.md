# Changelog

All notable changes to `bmad-specialist` should be recorded here.

## 1.1.0 - 2026-03-22

### Changed

- expanded the skill from a customization-surface explainer into a
  conversational installed-BMAD audit workflow
- added support for team alignment interviews around refinement and other shared
  process behavior
- added guidance for focused BMAD-role panel reviews using installed role files
  plus project-local customization context
- added durable customization audit report output with before/after outcome
  framing
- clarified when behavior should live in `_memory/`, `*.customize.yaml`, a BMAD
  workflow/checklist, or a standalone skill

## 1.0.0 - 2026-03-22

Initial release.

### Added

- explicit-only specialist skill for installed-project BMAD usage
- runtime map for the `_bmad/` project surface
- customization playbook for outputs, languages, agents, workflows, and memory
- safety guidance that distinguishes safer override layers from riskier direct
  edits
- quick reference for choosing the right customization surface
