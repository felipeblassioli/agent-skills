## [1.0.0] - 2026-03-20

### Added

- Initial release of the `code-review` skill.
- Structured review categories covering security, performance, code quality, and
  testing concerns.
- Reusable review output template for severity-based findings and positive
  observations.
- Concrete bad-versus-good examples for common review patterns such as SQL
  injection, N+1 queries, and swallowed errors.
