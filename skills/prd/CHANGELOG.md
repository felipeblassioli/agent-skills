# Changelog

All notable changes to this skill are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-05-05

### Added

- Initial release of the `prd` skill for generating structured Product Requirements Documents from discovery through technical specification.
- Added a strict PRD output schema covering executive summary, user stories, technical requirements, and rollout/risk planning.
- Added quality guidance emphasizing measurable requirements, explicit discovery questions, and anti-hallucination constraints.
