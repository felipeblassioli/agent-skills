## [1.0.0] - 2026-05-05

### Added

- Initial release of the `github-actions-release-topology` skill for designing and reviewing deterministic GitHub Actions CI/CD promotion topologies.
- Added production-readiness and promotion-safety guidance for quality gates, release evidence, cache discipline, OIDC boundaries, and environment controls.
- Added `references/topology-review-checklist.md` as the detailed criteria source for topology and release audits.
