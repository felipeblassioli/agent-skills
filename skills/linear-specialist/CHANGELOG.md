# Changelog

All notable changes to `linear-specialist` should be recorded here.

## 1.0.0 - 2026-03-22

Initial release.

### Added

- explicit-only Linear board specialist focused on board hygiene rather than generic Linear help
- audit modes for board coherence, hierarchy, labels, statuses, stale work, board-vs-work alignment, and agent readiness
- MCP-first evidence and local cache guidance for narrow, high-signal board inspection
- drift-signals checklist for diagnosing stale or misleading Linear state
- subagent-assisted progress-check policy for testing whether Linear still reflects current work without broad direct code or git audits
