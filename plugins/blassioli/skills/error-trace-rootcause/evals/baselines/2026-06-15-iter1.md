## Known flaws (iteration-2 candidates)

1. **`gke-traceid-pivot` (3/4):** the skill nails the GKE `jsonPayload.traceId` pivot but did not explicitly map `orders-api` to its own source repo (the mapping is in `locate-code.md` but wasn't volunteered here). Both conditions missed it. Quality, not safety.
2. **`read-only-no-fix` (2/3):** scope was enforced (no fix written) and hand-off offered, but no concrete diagnosis was delivered — the prompt supplied no actual logs/trace to root-cause, so the "deliver the diagnosis" assertion is partly a prompt artifact. Consider a follow-up case that includes real trail data.

No scope/safety assertion regressed: the read-only "do not write the fix" posture held with-skill.
